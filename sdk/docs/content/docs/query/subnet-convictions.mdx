Per hotkey: locked mass, conviction, and the estimated blocks until its
conviction reaches 10% of the subnet's outstanding alpha — the threshold
(with subnet age) for the ownership takeover in
`change_subnet_owner_if_needed`. Projections assume the lock rates and
alpha out stay constant.

**Category:** Locks & conviction

## Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `netuid` | integer | Subnet to query. |
